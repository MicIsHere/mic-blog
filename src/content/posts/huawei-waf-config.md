## 将内网设备的端口映射到公网，并自动绑定到现有的接口IP
:::warning[不要改动服务器映射设置]
命令行配置后不要进入 WebUI 改变其设置，会导致接口绑定失败  
_改完之后你的 IP 又变成手动输入的了_
:::
华为的这个WebUI吧，比较抽象  
![](https://cdn.imgos.cn/vip/2026/03/28/69c7f36bdf019.png)  

你创建服务器映射的时候，需要填写一个公网地址，并且还没有绑定接口的选项 ~~_企业级可能不太需要WebUI吧_~~   
但是我用的家宽导致IP会变，查询后发现只能用命令创建   
![](https://cdn.imgos.cn/vip/2026/03/28/69c7f36b8e477.png)

可以用Command线或者是右下角这个 CLI控制台，进入命令行   
![](https://cdn.imgos.cn/vip/2026/03/28/69c7f5f50f08d.png)
输入以下命令，回车即可  
```
<Eudemon1000E-M> system-view # 进入系统页面
Enter system view, return user view with Ctrl+Z.
[Eudemon1000E-M] nat server <名称> protocol <网络协议 tcp/udp> global interface <接口ID，默认应该为Dialer0> <外网端口> inside <内网IP> <内网端口> no-reverse
```
